# ADR-0001: 모놀리스 → MSA 전환에 Strangler Fig 패턴 채택

> ADR(Architecture Decision Record) = "왜 이렇게 결정했는지" 기록. 면접에서 그대로 근거로 쓴다.
> @PHASE: — (전 과정 관통)
> @DEEP 아래 뼈대만. 실제 전환 진행하며 "결과/교훈" 채움.

## 상태
제안됨 (Proposed)

## 맥락
K-portfolio(Boot 3.2 모놀리식)를 한 번에 재작성하면 리스크가 크고 롤백이 어렵다.

## 결정
게이트웨이 뒤에서 도메인을 하나씩 서비스로 떼어낸다(Strangler Fig). 각 단계는 라우트 전환만으로 롤백 가능.

## 결과
- 장점: 점진적, 언제든 롤백, 기존 기능 무손상.
- 비용: 전환 기간 동안 모놀리스+서비스 공존, 게이트웨이 라우팅 관리 필요.
